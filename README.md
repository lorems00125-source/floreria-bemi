# 🌸 Florería BEMI

Bienvenido a **Florería BEMI**, una tienda en línea sencilla para ofrecer ramos de flores, girasoles, cajas y complementos.  
Creada con **HTML, CSS y JavaScript puro**, y desplegada en **Netlify**.

---

## 🚀 Características
- ✅ Catálogo organizado en secciones:
  - Rosas Rojas
  - Girasoles
  - Cajas
  - Complementos
- ✅ Precios, nombres y descripciones editables desde el código.
- ✅ Animaciones en imágenes (efecto zoom al pasar el mouse).
- ✅ Carrito de compras con cálculo automático del total.
- ✅ Botón de WhatsApp para confirmar pedido con la lista y el monto total.
- ✅ Instrucciones visibles para guiar a los clientes.

---

## 🛠️ Tecnologías usadas
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **Netlify** (para el despliegue)

## 🛒 Cómo funciona la compra
1. Elige un producto en cualquiera de las secciones.
2. Haz clic en **"Agregar al carrito"**.
3. El carrito mostrará todos los productos seleccionados y el total.
4. Presiona **"Comprar"** → Se abrirá WhatsApp con el pedido listo para enviar.

---

## ✏️ Personalización
Para cambiar **precios, nombres o descripciones**:
1. Abre el archivo `index.html` en VS Code.
2. Ubica el bloque `const secciones = [...]`.
3. Edita los valores de:
   - `"nombre"`
   - `"precio"`
   - `"descripcion"`
   - `"imagen"`
4. Guarda los cambios y vuelve a subirlos a GitHub (`git push`).

---

## 🚀 Despliegue con Netlify
Este proyecto está configurado para desplegarse automáticamente desde GitHub.  
Cada vez que se haga `git push` a la rama `main`, Netlify actualizará el sitio.
